In build 13 (also in this build)
-------------------------------
  ✓ CT7-067 Tenant dashboard could show "Welcome back, Tenant" with no home
    after sign-in. Most likely cause (from the code; reproduced in Jest, not
    seen again on the device): sign-in did not wait for the login session to
    be stored, and when that step failed silently every screen loaded with
    no session. Sign-in now completes only once the session is stored and
    the profile loaded, and otherwise says "Couldn't finish signing in";
    session storage can no longer lose the session; the tenant dashboard
    shows "Couldn't load your dashboard" + Try Again instead of an empty
    page (#272)
  ✓ CT7-066 (database) Maintenance requests: a tenant can only create one
    with a lease in effect on that property, an owner only on a property
    they own — now enforced by the database, not just the app. Before this,
    any signed-in tenant or owner could create a request on any property
    through the API. Applied to production 2026-11-20 and verified (#273)
  ✓ CT7-070 lifecycle-03a test fix (#270, carried from build 12 record)
