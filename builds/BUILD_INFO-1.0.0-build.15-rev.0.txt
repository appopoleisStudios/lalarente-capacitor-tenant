Client release notes — everything since build 11
================================================
(Build 11 was the last build the client received. Builds 12-14 were
internal. Build 15 installs over build 11 and keeps the data.)

Everyone (Android)
  - Screens, bottom tabs and pop-up sheets no longer hide under the
    Android status bar or navigation buttons; the clock, battery and signal
    stay visible.
  - The keyboard no longer covers form fields or buttons, in pop-ups or
    full screens.
  - Alerts keep all their buttons.
  - Dates read "19 Nov 2026" everywhere and viewing times "Fri, 20 Nov at
    10:00"; no raw technical values on screen.
  - Opening Notifications no longer marks everything read; only the one you
    tap is cleared.
  - Signing in finishes properly; if it can't, it says so instead of
    opening an empty screen.
  - Report PDFs export reliably, including right after the app starts.

Owner
  - Leases can be signed on Android; the signature date fits and signature
    images show.
  - Signing a lease can no longer hang on making the PDF; if the PDF fails,
    you're told to tap "Generate PDF".
  - Rent Roll no longer shows unpaid rent as "Paid"; the dashboard "In
    Arrears" and Rent Roll "Overdue" agree.
  - Recent Activity rows on the dashboard open their item.
  - Back from a maintenance request no longer loops.
  - Property Type is a choice (Apartment, House, Townhouse, Cottage or
    Room).
  - Property search with no match says so and offers "Clear filters".

Tenant
  - Leases can be signed on Android.
  - "Add Comment" on an inspection report stays above the keyboard.
  - Report Issue is available once the lease is signed by both sides and
    in effect.
  - The dashboard no longer shows "Welcome back, Tenant" with no home; if
    it can't load, it says so with "Try Again".
  - Profile badge and dashboard banner agree on what's missing.
  - "Verify Completed Work" has a back arrow.

Vendor
  - You can open a quote you submitted.
  - "View My Jobs" opens your job list.

Security (no visible change)
  - Only people involved in a maintenance request can change it.
  - Maintenance requests can only be created by the property's owner or a
    tenant with a lease in effect there.

Known open items (not in this build)

  - Android sheet guards skip steps whose data isn't on the test fixture

  - Board items CT7-034..042 (from the client's build 11 test) are still

  - Notifications sent before build 13 keep their old date text.
  - Carried over from build 11: documents bucket public-flagged; lease
